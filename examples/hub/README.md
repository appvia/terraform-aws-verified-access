# Hub and spoke example

A hub VPC holding the Verified Access endpoints and the central load balancer, a spoke VPC holding a private SSH host, and a transit gateway between them. The module is called with `topology = "hub"`: the endpoint's `targets` become an IP target group behind a listener on the central load balancer, so engineers reach the host in the spoke with the Connectivity Client. Alarms (to a new SNS topic) and a CloudWatch dashboard are switched on; a module requested certificate for http endpoints is shown commented out.

The target's address is fixed so that it is known at plan time, as load balancer targets must be.
